# EBAC - FullStack Designer

## Exercício prático referente ao módulo 13 sobre Bootstrap avançado

### A entrega deste exercício consistia em:

• Criar um projeto utilizando o Bootstrap com os elementos:

- Carousel de imagens;
- Um layout com grid, onde na visão desktop haverá 3 itens por linha, no tablet 2 itens por linha e no smartphone 1 item por linha;
- Inserir um card dentro das colunas.
